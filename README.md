# Form & Field

A Flutter experiment combining a website, a photo browser, a freehand drawing surface, and a parametric pavilion. The application UI and geometry are authored in Dart under `lib/main.dart`; `assets/images/` contains eight bundled photographs from Unsplash. The repository targets Flutter web.

## Run and build

Requires Flutter 3.47.1 or newer (tested with 3.47.9) and Dart supplied by Flutter. In PowerShell from this folder:

```powershell
flutter pub get
flutter run -d chrome
flutter build web --release
```

Web output is `build/web`; serve that directory with any static HTTP server. Navigation uses Flutter's default hash URLs, which work on ordinary static hosting. For a subdirectory deployment, pass the appropriate `--base-href /your/path/` to `flutter build web`.

Dependencies: Flutter, `go_router`, `flutter_scene` and `vector_math`. Scene uses Flutter GPU on native platforms and its own WebGL2 backend on web. Web scaffolding is generated by Flutter; no HTML, CSS, or JavaScript was handwritten. Scene and Flutter include their own non-Dart runtime and shader components.

## Controls and limitations

Gallery: search, category filters, reverse sorting, thumbnails, previous/next and pinch/scroll image zoom. Photos are bundled; the gallery has no backend. Images were sourced from Unsplash (`images.unsplash.com`); check the Unsplash license and individual image rights before redistribution.

Graphicpad: choose Pen to draw, Select / move to click near a stroke and drag it, use Delete to remove a selected stroke, Undo for the last stroke, middle-drag to pan, scroll or buttons to zoom. Pen pressure influences the width at the start of a stroke where the platform reports a pressure range; pressure is not continuously interpolated. The canvas has no persistence, export, redo, shape editing, multitouch pan, or advanced smoothing.

Architecture: sliders regenerate cuboid geometry; material chips recolor the pavilion. Drag to orbit; pinch, scroll, or use the zoom buttons to zoom. Studio environment lighting comes from Flutter Scene. There is no object picking, pan, editable individual components, or save/export. This is a simple massing study rather than a full architectural CAD tool. GPU/WebGL2 support depends on the device and browser. Scene's native rendering depends on Flutter GPU support.

State is in memory and is lost on reload or route changes. This is an experiment, not a production-ready editor. No visual or interactive testing was performed.
